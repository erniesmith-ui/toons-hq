# toons-hq

Private working repo for Toons USA / Toons Eufaula. Start at [AGENTS.md](AGENTS.md).

Each workspace is a folder of plain markdown: numbered steps say what happens in what order, each step's `CONTEXT.md` says what it reads, does, writes and how it's checked, and `_shared/` holds the rules that stay the same every time. Any person or AI agent can open a folder and see where things stand.

Method: Interpretable Context Methodology (Van Clief & McDermott, arXiv:2603.16021). `_tools/links.py` and `_tools/index.py` come from github.com/RinDig/icm-architect (MIT).
